# 桃園下一班

以手機為主要使用介面的 GitHub Pages 個人公車工具。以瀏覽器定位尋找桃園附近站點，自動選最近站牌，顯示路線方向與到站預估，支援站名搜尋與手動語音朗讀。

## 使用

https://voidlmao.github.io/taoyuan-next-bus/

Safari 分享選單可加入主畫面。定位需要 HTTPS 及位置權限；拒絕定位仍可搜尋站名。沒有背景位置追蹤或背景通知。

## 資料來源與限制

直接呼叫桃園市公車動態網站公開 GraphQL 端點 `https://ebus.tycg.gov.tw/ebus/graphql`，不需 API 金鑰、不使用第三方代理、不儲存位置。查附近站牌時會把座標傳至官方服務。非官方作品；端點可能改版、限制存取或中斷，若來源失效須調整介接。

只合併名稱及座標完全相同的站點紀錄；不同座標、同名站牌仍分開，避免混合道路兩側。站點按直線距離排序，不代表步行距離或路線安全；每條路線標示目的地供確認。即時 etaTime 單位為分鐘，預定時刻與即時預估分開；無預估不等於沒有公車。資料超過 90 秒不再顯示為有效到站資訊。前景每 30 秒更新，不模擬來源未提供的倒數。

## 開發

原生 HTML/CSS/JavaScript，無建置或套件需求。以任意靜態 HTTP 伺服器預覽。`npm test` 執行核心資料邏輯檢查。GitHub Pages 設定 main 分支根目錄。
