# 桃園下一班

以手機為主要使用介面的 GitHub Pages 個人公車工具。以瀏覽器定位尋找桃園附近站點，自動選最近站牌，顯示路線方向與到站預估，支援站名搜尋與手動語音朗讀。

## 使用

https://voidlmao.github.io/taoyuan-next-bus/

Safari 分享選單可加入主畫面。定位需要 HTTPS 及位置權限；拒絕定位仍可搜尋站名。沒有背景位置追蹤或背景通知。

## 資料來源與限制

直接呼叫桃園市公車動態網站公開 GraphQL 端點 `https://ebus.tycg.gov.tw/ebus/graphql`，不需 API 金鑰、不使用第三方代理、不儲存位置。查附近站牌時會把座標傳至官方服務。非官方作品；端點可能改版、限制存取或中斷，若來源失效須調整介接。

只合併名稱及座標完全相同的站點紀錄；不同座標、同名站牌仍分開，避免混合道路兩側。站點按直線距離排序，不代表步行距離或路線安全；每條路線標示目的地供確認。即時 etaTime 單位為分鐘，預定時刻與即時預估分開；無預估不等於沒有公車。資料超過 90 秒不再顯示為有效到站資訊。前景每 30 秒更新，不模擬來源未提供的倒數。

## 開發

原生 HTML/CSS/JavaScript，無建置或套件需求。以任意靜態 HTTP 伺服器預覽。`npm test` 執行核心資料邏輯檢查。GitHub Pages 設定 main 分支根目錄。

## 路線查詢

「查路線」可搜尋公車號碼，選去程或返程，按官方站序查看各站下一班的到站預估。117、151、152、GR 提供捷徑。附近站牌的公車號碼也可直接點選進入路線。各站下一班不一定是同一輛車；沒有即時資料時標示預定時刻或暫無資料，畫面開啟時每 30 秒更新。

## 地標與地址導航

「導航」輸入地標或地址，選定目的地後，從目前位置尋找可直達的公車。使用 Photon/Komoot 公開地理搜尋服務（OpenStreetMap 資料），並以桃園公車站名搜尋補充；只在使用者送出搜尋時查詢、節流並在本次頁面快取，不建立目的地歷史。公共地理搜尋服務不保證可用性，地址或新地標可能未收錄。公車比對依兩端附近站點的共同路線、同方向及上下車先後順序進行，不假設同名站牌可互換。直達與一次轉乘候選均依桃園資料比對；顯示直線距離，步行路徑請開啟地圖。上下車範圍可調整。為控制單次資料量，最多比對起點最近600、目的地最近400筆站牌紀錄及有限筆端點路線，超出或有資料失敗會提示結果可能不完整。到站時間超過90秒後標記需更新。地理服務只收到輸入的搜尋文字，GPS座標僅用於桃園官方附近站牌查詢，步行導航按下連結後交由Google地圖處理。


導航更新：選定地標或地址後，主要入口可開啟 Google 地圖大眾運輸（目的地使用名稱與地址，起點由地圖定位或手動輸入），供跨市、公車、捷運與鐵路接續規劃。站內「桃園公車」展開後會比對直達及一次轉乘候選，兩段均須依站序前進，轉乘點相距不超過250公尺直線距離，不能以同名站假設可轉乘。路徑不是班表銜接結果，不估計全程時間或宣稱接得上；第二段須於抵達時重查。每端最多取20條路線及20條共同路線，超出會提示，缺資料不代表沒有交通方式。
